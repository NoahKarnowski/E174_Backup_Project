2.2 Clean and Join into Tsibble

Here, the chunk below selects the relevant columns from each CSV and removes the rest, then left joins the tables together to make a singular reference table. This master table is also cleaned, set to a tsibble format for time series analysis, and adds logged versions of each varaible’s values for future analysis.

Code 
US_DD <- US_DD %>%
  dplyr::select(date = TIME_PERIOD, country = REF_AREA,
                domestic_demand = OBS_VALUE)

US_GDP <- US_GDP %>%
  dplyr::select(date = TIME_PERIOD, country = REF_AREA,
                gdp = OBS_VALUE)

US_IMP <- US_IMP %>%
  dplyr::select(date = TIME_PERIOD, country = REF_AREA,
                imports = OBS_VALUE)

us_clean <- US_DD %>%
  left_join(US_GDP, by = c("date", "country")) %>%
  left_join(US_IMP, by = c("date", "country")) %>%
  mutate(date = yearquarter(date)) %>%
  group_by(date, country) %>%
  summarise(
    domestic_demand = sum(domestic_demand, na.rm = TRUE),
    gdp             = sum(gdp,             na.rm = TRUE),
    imports         = sum(imports,         na.rm = TRUE),
    .groups = "drop") %>% as_tsibble(key = country, index = date)

# Add log-transformed columns — stabilises variance and linearises growth
us_clean <- us_clean %>%
  mutate(
    log_gdp             = log(gdp),
    log_domestic_demand = log(domestic_demand),
    log_imports         = log(imports)
  )

5 ETS Modelling

ETS (Error, Trend, and Seasonal) models decompose a series into three exponentially smoothed components. Since all series are log-transformed, additive ETS on the log scale here is equivalent to multiplicative ETS on the original scale.

5.1 Fit Multiple ETS Specifications

Five specifications are fit per variable: an automatically selected model, two damped/undamped additive variants, and one full additive seasonal model. Residuals are being checked before using the models for forecasting to confirm the data has white-noise for the remainders.

5.3 ETS Residual Diagnostics

Residuals are checked on the auto-selected model (best AICc candidate) before forecasting. A well-specified model should show 3 main traits: no autocorrelation in the time plot, ACF values within 95% bounds, and a normally distributed histogram.

Analysis: Examine each panel. The 2020 COVID shock still appears strongly on the time plot, but otherwise the mean is 0 for every variable in the best ETS models. All gg_tsresiduals plots for each ETS have ACF values within the 95% boundary, and a normally distributed histogram. We can therefor conclude that taking the log of the variables has given us stationary data to work with that’s white noise. An Ljung-Box test will also be performed.

5.4 Ljung-Box Test on ETS Residuals

The Ljung-Box Test on our ETS models has a null hypothesis that there is no autocorrelation in our variables. If the p-value is below 0.05 as our threshold, we reject the null hypothesis and say that some autocorrelation is present.

6 ARIMA Modelling

ARIMA models use lagged values and lagged errors to capture autocorrelation structure after differencing to achieve stationarity. The differencing order of “d” is determined by unit root tests; seasonal differencing of “D” is evaluated by comparing AICc values.

6.1 Unit Root Tests and Differencing Diagnostics

6.1.1 ACF of Log Levels

Analysis: A slow, linear decay in the ACF is the most obvious sign that the data needs to be transformed. The data is clearly non-stationary, especially since we saw at the very beginning a strong positive trend.

6.1.2 KPSS Tests and Recommended Differencing Order

KPSS tests being used below are another way we will be confirming whether our data is stationary for ARIMA use (as it’s required). KPSS tests assume a null hypothesis that the data is stationary and that no unit roots are present. We will again use a 0.05 threshold to determine if this criteria is met.

8 VAR Modelling

VAR (Vector Autoregression) jointly models all three variables as a system, allowing each variable’s forecast to be informed by the lagged values of the others. This captures cross-variable dynamics (e.g., imports responding to GDP growth with a lag) that univariate ETS and ARIMA cannot.

VAR requires stationary inputs. Because all three log series have unit roots (difference = 1), we work with first-differenced log series.

8.1 Prepare Differenced Data

Code 
us_clean_diff <- us_clean %>%
  mutate(
    d_log_gdp     = difference(log_gdp),
    d_log_dd      = difference(log_domestic_demand),
    d_log_imports = difference(log_imports)
  ) %>%
  filter(!is.na(d_log_gdp))

us_train_diff <- us_clean_diff %>% filter(date <= yearquarter("2023 Q4"))
us_test_diff  <- us_clean_diff %>% filter(date >= yearquarter("2024 Q1"))

# Remove tsibble key for vars package compatibility

10 Conclusion

Summary of Findings:

All three US national accounts series — GDP, domestic demand, and imports — exhibit strong upward trends with stable quarterly seasonality and remainder variance dominated by two structural breaks: the 2008–09 Global Financial Crisis and the 2020 Q2 COVID-19 collapse. The log transformation effectively stabilises variance, and first-differencing achieves stationarity as confirmed by KPSS tests.

ETS models capture the trend-seasonal structure well. The auto-selected specification will likely be an AAN or AAA model. The primary limitation is that ETS treats the COVID outlier as a one-period shock and reverts to trend quickly — this can produce overconfident forecasts if the post-COVID recovery trajectory differs from pre-pandemic trend.

ARIMA models additionally capture short-run autocorrelation structure in the differenced series. Seasonal ARIMA specifications may improve on purely non-seasonal models given the confirmed quarterly seasonal pattern in STL. ARIMA tends to produce better short-horizon forecasts for series with residual autocorrelation after differencing.

VAR captures cross-variable dynamics. GDP, domestic demand, and imports are theoretically linked — import demand depends on domestic demand and income (GDP). The VAR’s advantage is that lagged values of one variable can improve forecasts of another. On the differenced scale, this may matter most for imports, which is the most volatile of the three series.

The COVID structural break is the primary caveat for all three models. Intervention modelling or out-of-sample evaluation restricted to the post-2021 recovery period would provide a cleaner picture of forecasting performance in the current macroeconomic environment.
